# Templates D, E, F — 3 New Pin Styles (2026-08-10)

Three additional pin templates for britishhomeinterior.co.uk, built for the Room
Makeovers / general decor boards using the same structural concepts approved on the
Canada site (SmallSpace Home), adapted to this site's own "National Trust heritage"
brand kit rather than reusing Canada's palette: green `#47612F` (deep `#33461F`), ecru
`#F3F4EF`, gold `#B89A6A`/gold-light `#D4BE93`, ink `#1A2318`. Fonts: Playfair Display
(headline), Lato (kicker/domain/subtitle).

Distinct in silhouette from the existing A (full-bleed moody) / B (split panel) / C
(heritage plate) set — and from each other.

## Template D — "Taped Polaroid"

Scrapbook feel: textured ecru paper background, the cover photo taped in at a slight
tilt like a real polaroid with visible tape corners, kicker above, headline and subtitle
below.

## Template E — "Price Tag"

Full-bleed photo with a hanging gold price-tag graphic in the top-left corner and a torn
banner carrying the headline and subtitle lower on the frame.

## Template F — "Archway"

Deep green solid-color canvas with the photo revealed through an architectural arched
frame (a nod to real period UK doorways), headline and subtitle on a draped ribbon
banner beneath the arch.

---

120 pins generated: all 40 articles already covered by Template A now also have the
full D + E + F set, reusing each article's existing kicker/headline/photo for the
on-image graphic copy (with the kicker's mojibake middle-dot bug — "Â·" — cleaned up to
a proper "&middot;" for these new templates only; the existing A/B/C pins were not
touched), plus the site's separate optimized Pinterest subtitle copy rendered directly
on the pin beneath the headline.

Also upgraded the generator to retina (2x) output for these new templates, matching the
Canada site's already-upgraded pins — a 1000x1500 pin now renders as a 2000x3000 PNG.

## Source

- Template code: `pin-generator/generate-pins.mjs` (templates `D`, `E`, `F`)
- Batch spec: `pin-generator/pins-uk-template-def.json` (120 entries: 40 articles × 3
  templates)
- Generation command: `node pin-generator/generate-pins.mjs pin-generator/pins-uk-template-def.json`
  (run from the site root — relative photo paths resolve against the repo root)
